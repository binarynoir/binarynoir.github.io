# Section Glossary Demo

A live example of [section glossaries](/plugins/glossary#section-glossaries). This folder has its own [glossary file](/plugins/glossary-demo/section-glossary), so its terms apply to this page and nowhere else on the site. Hover, click or tap a dotted word to read it.

- **Gizmo** exists only in this folder's glossary.
- **CI** is defined by both this folder's glossary and the site's master glossary. The closer one wins, so you see the demo's definition here.
- **CLI** is defined only by the master glossary, so it still works. A section glossary adds to the master; it doesn't replace it.

On the [plugin page](/plugins/glossary), CI shows the master's definition and Gizmo has no tooltip.
