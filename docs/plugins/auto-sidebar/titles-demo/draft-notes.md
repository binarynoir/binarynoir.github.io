# Draft notes ((tag|draft|orange))

This heading carries a [Markdown Tags](/plugins/markdown-tags/) badge, written as `((tag|draft|orange))`. On the page it renders as a badge. In the sidebar, [Auto Sidebar](/plugins/auto-sidebar/) removes the tag syntax, so the entry reads **Draft notes**.

That is `stripTags`, on by default. Set `stripTags: false` to keep the raw syntax in titles.
