# Apps

[[readingTime]]

Small command-line tools for people who would rather be told when something changes than keep checking. Each one is a single self-contained program that installs with one Homebrew command.

| App                          | What it does                                         | Written in          |
| ---------------------------- | ---------------------------------------------------- | ------------------- |
| [NoirWatch](/apps/noirwatch) | Watches web pages and notifies you when they change. | ((tag/Shell/grey))  |
| [NoirCon](/apps/noircon)     | Tells you when a site, server or port goes down.     | ((tag/Shell/grey))  |
| [callrx](/apps/callrx)       | Amateur radio callsign lookup in your terminal.      | ((tag/Rust/orange)) |

## For users

You don't need to be a developer. If you can paste a command into a terminal, you can install any of these. Start with the page for the app you want. Each one explains what it is for, how to install it, and the first commands to run. Homebrew installs work on macOS; the pages also cover other ways to install.

## For developers

Each app is open source and welcomes issues and pull requests on its repository. The [roadmap](/apps/roadmap) collects the `Done` and `Planned` status tags from the app pages into one list, so you can see what is finished and what is coming.
