# Services ((tag|Consulting|blue))

[[readingTime]]

Your docs live in one tool, your tickets in another, and meeting notes wherever someone saved them. Finding out where a project actually stands means chasing people.

We fix that. We set up one docs site for your team, connect it to your tickets and meeting notes, and set up AI that can read all of it. We've done this for two companies so far. This site is the public example: it runs on the same [plugins](/plugins/) we'd use for you.

[See services and rates](#services) · [Email us](mailto:hello@binarynoir.tech?subject=Services%20enquiry)

## What changes for your team

- **Managers** ask for a progress report and get one in a minute, built from the tickets. No more chasing updates before a meeting.
- **Everyone** finds docs, decisions and meeting notes in one place, so there are fewer "where's that doc?" messages.
- **New hires** learn the project from the docs instead of pulling someone off their work.
- **Leads** get AI reviews that check work against your team's own rules, so standards hold without someone policing them.

## What we set up

- **A docs site built from your folders.** Add a Markdown file and it shows up, with navigation, search and a glossary.
- **Tickets in Markdown**, in a format people and AI can both read.
- **Claude, set up for your project**, with your conventions, your standards and a review checklist.
- **Meeting notes linked to the work.** Transcripts become notes, decisions and action items.
- **Your other tools connected.** Jira, Azure DevOps, Linear, Craft and similar tools, imported or linked so nothing goes stale.

## Common questions

**Do I have to use your plugins?**
No. They're free and MIT-licensed, and they're what we know best. If your team already has a docs tool that works, we'll build on that.

**Who owns the work?**
You do. The site, the templates and the instruction files are all yours.

**Can AI see our private data?**
Only what you decide. We agree up front which tools and folders the AI can read, and nothing goes into a tool your team hasn't approved.

**How does payment work?**
Strategy sessions and hourly work are invoiced when the work is done. Starter builds are half up front and half at handover. Ongoing help is billed at the start of each month.
