# Strategy session ((tag|2 hours|blue))

[[readingTime]]

A two-hour working session for a team that wants to run its work from docs, tickets and AI, and build it themselves. You leave with decisions made and a short plan, not a slide deck.

## Before the session

Send us a few lines on:

- What your team does and how many people are on it
- Where your tickets, docs and meeting notes live today
- The one report or question you wish took less time to answer

We'll come prepared with a starting point that fits your setup.

## What we cover

| Time   | Topic                  | What we decide                                                                                |
| ------ | ---------------------- | --------------------------------------------------------------------------------------------- |
| 15 min | Where you are now      | What works, what doesn't, and the report you most need                                        |
| 30 min | Tool choice            | Where docs and tickets live, whether you need a docs site yet, and what to keep vs. replace   |
| 30 min | Ticket structure       | A Markdown ticket template: fields, statuses and the sections AI needs to report on           |
| 30 min | Wiring up AI reporting | How Claude reads the board, the instruction file that teaches it your project, a first report |
| 15 min | Next steps             | A short list of what to build first, in order                                                 |

The times move with your needs. If tool choice is already settled, we spend that time on the parts that aren't.

## What you leave with

- A ticket template you can start using the next day
- A starter instruction file for Claude, written for your project
- A short, ordered build plan
- Notes from the session
